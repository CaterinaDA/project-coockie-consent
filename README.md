# Project: Cookie Consent

## Description
This project was created as part of the *Frontend Developer Career Path* on Scrimba.  
It simulates a cookie consent popup that asks for the user's name and email address, showing different responses depending on their choice.  
The goal is to practice working with **JavaScript events, modals, and dynamic content updates**.

---

## Features
- Popup modal that appears on page load.
- User input validation through a consent form.
- “Accept” and “Decline” buttons with different outcomes:
  - Accept → loading spinner, thank-you message.
  - Decline → humorous GIF reaction.
- Form disable states and dynamic text updates.
- Modern layout using Flexbox and CSS animations.

---

## Technologies Used
- HTML5
- CSS3 (Flexbox, responsive layout, typography)
- JavaScript (DOM manipulation, event listeners, form handling)
